# Prompt Pulse - Backend API

This package contains the Hono-based API for Prompt Pulse.

## Development

Currently set up for local development using Node.js and `@hono/node-server`.

1. Install dependencies from the project root.
2. Run `npm run dev` in this directory to start the local server on port 3001.

## Production

We plan to deploy this to Cloudflare Workers using Wrangler later in the development process.
